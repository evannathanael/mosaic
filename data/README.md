# Data folder

This folder is gitignored (except structure) since datasets are too large for git.

## Expected layout after running `src/data/download.py`

```
data/raw/
├── sid_set/
│   ├── real/...
│   └── ai/...
├── cifake/
│   ├── real/...
│   └── ai/...
└── wildfake/
    ├── real/...
    └── ai/
        ├── <generator_name_1>/...
        └── <generator_name_2>/...
```

`scan_dataset()` in `src/data/dataset.py` walks this structure automatically.
The `wildfake` generator subfolders are what let us hold out one entire
generator for the "unseen generator" robustness test (see `configs/config.yaml`
-> `data.holdout_generator`).

## Validation subset (demo only — DO NOT train on this)

Per the challenge instructions, a separate validation subset (COCO val2017 for
non-AIGC, DALL·E Advanced for AIGC) is provided purely for demonstrating your
model's performance — it does not contribute to the final score and must not
be used for training. Keep it in a separate folder, e.g. `data/validation_demo/`,
never inside `data/raw/`.

## Near-duplicate test set

Generated by `src/data/near_duplicate_gen.py` into `data/near_duplicates/`,
with a `manifest.json` giving ground-truth cluster labels for evaluating the
similarity/clustering system in `src/similarity/clustering.py`.

## Cleaning CIFAKE

Keep the Kaggle download unchanged under `data/raw/cifake/`, with its original
`train/{REAL,FAKE}` and `test/{REAL,FAKE}` folders. Then run:

```bash
python -m src.data.clean_cifake
```

The command prints a progress line every 1,000 files. Use
`--progress-every 100` for more frequent updates, or `--progress-every 0` to
disable progress output.

The command validates image decoding, inventories dimensions and hashes,
excludes exact duplicate leakage, and writes non-destructive outputs to
`data/processed/cifake/`:

- `clean_manifest.csv`: rows approved for downstream training/evaluation
- `manifest.csv`: every valid row, including excluded duplicates and reasons
- `rejected.csv`: unreadable images or paths with ambiguous split/label metadata
- `near_duplicate_review.csv`: perceptual-hash matches requiring manual review
- `cleaning_report.json`: summary counts for the team

The cleaner preserves CIFAKE's supplied split and labels. It does not resize or
rewrite the 32x32 raw images.
